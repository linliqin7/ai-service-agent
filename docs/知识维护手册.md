# 知识维护与发布

知识位于 `app/rag/fixtures/knowledge.json`。本地页面为只读检视，导入是操作员命令，不开放匿名上传接口。

## 条目结构

每条记录包含 id、title、domain、version、source、source_url、effective_at、expires_at、review_status、audience、scope、direct_answer、text、keywords。失效时间不包含在有效区间内。当前演示条目的 source_url 留空，避免把未读过的官方网页伪装成依据。

## 新增或修订

1. 先确认资料原文、适用人群、市场、发布主体和时间；记录待审核版本。
2. 按完整业务规则切分，保留例外条件，不把门槛数字和适用范围拆开。
3. 当前导入器接受已结构化的 JSON 数组，每条 text 10–5000 字符；没有 PDF/OCR 自动解析，也不会自动获得合规审核。
4. 使用新 ID 发布新版本；已有同 ID 不允许不同内容覆盖。同名规则有效期重叠会被拒绝。
5. 修订旧版的失效时间或停用状态必须先备份原文件，再由本地维护者更新。旧版本应保留用于审计，不能静默替换原始依据。
6. 运行命令：`PYTHONPATH=. .venv/bin/python -m app.rag.ingest 待导入.json`。
7. 加入能够命中新版、排除旧版、覆盖例外条件的样本，再运行测试和评测；保存变更理由。

## 修复归因表

| 现象 | 检查依据 | 修复动作 | 回归样本 |
|---|---|---|---|
| 内容缺失 | 当前知识无对应条款 | 补充有来源的内容，未补齐前人工出口 | 新业务标准问法 + 近义问法 |
| 切分不当 | 条件和例外分离 | 以完整规则单元重切并保留关联 | 带例外条件的边界问题 |
| 改写失败 | 查询词未映射到业务术语 | 增加受控同义映射 | 原口语表达及易混邻域 |
| 检索域错误 | 命中文档来自其他业务 | 修复域选择、关键词与最低充分性条件 | 同词不同意图的问题 |
| 词法召回不足 | 原文有内容但重叠词少 | 建立召回基线后试验向量召回 | 语义相同但词面不同的留出样本 |
| 排序错误 | 正确依据不在前列 | 调整加权或引入经评测的重排 | 多候选文档样本 |
| 过期知识 | 引用版本超出有效期 | 生效区间过滤、退役与冲突检测 | 时间边界前一天/当天 |
| 生成偏离 | 引用正确但添加事实 | 约束生成，数字检验或摘录降级 | 不在资料内的数字/时限 |
| 不该回答 | 错路由或风险绕过 | 修正输入/输出策略，不只改提示词 | 对抗与误杀对照样本 |

当前数字校验只证明答复数字出现在引用正文中，无法证明语义关联正确；完整事实准确率仍需人工审查。引用 ID 存在也不等于引用支持了每句话。
