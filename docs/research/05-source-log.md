## 后续核验顺序

1. 证监会：投资者适当性、证券投资顾问资质、投资者保护和个人信息保护相关规则。
2. 上交所：科创板投资者适当性、交易和交收规则。
3. 深交所：创业板投资者适当性、交易和交收规则。
4. 北交所：投资者适当性、交易和交收规则。
5. 券商官方帮助中心：开户、权限、账户、订单和人工客服流程。
6. 同花顺公开资料：To C 产品、机构服务和 AI 产品边界。

## 引用纪律

- 规则数字必须记录文件标题、发布机构、发布日期/生效日期和原文链接。
- 不同券商的执行口径不能直接合并成“行业统一规则”。
- 无法找到当前生效官方原文时，只记录为待核验，不写入 Agent 的确定性回答。
- 官方宣传材料用于证明“产品声称具备什么”；真实能力必须通过产品走查或可复现操作验证。
