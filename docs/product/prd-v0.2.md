# Historical PRD — 券商经纪业务智能客服 Agent PRD v0.2

> Historical product document, dated 2026-09-15. It records the scope before Task State, task-bound Evidence, and the Answerability Gate were added. It is retained as project-evolution evidence and is not the current product specification. See the root [PRD.md](../../PRD.md) for the v1.0 specification.

## 产品定位

To B to C 的经纪业务客服：付费方假设为券商，终端使用者为个人投资者，业务和合规负责口径治理，人工坐席承接复杂问题。长期可以发展为金融助手，第一期不做个性化投资推荐、主动营销、预测收益或代客交易。

本项目证明任务编排和控制机制可运行，不证明市场规模或商业 ROI。没有券商内部日志，需求频率、人工成本和客户留存影响均未量化。

## 问题与价值假设

1. 同样出现“开户”这个词，可能问材料，也可能查询个人审核状态；系统应先识别任务而非直接命中文档。
2. 个人状态和订单必须来自有权限的接口，不能由模型凭常识生成。
3. 非标准表达需要语义识别和澄清，但合规、鉴权、资源归属及高风险动作不能交给模型自主决定。
4. 成功标准是有依据地完成可支持任务，同时给不支持的任务明确出口。降低人工率不能优先于正确性与安全。

## 用户画像

资产层级与生命周期两个维度：覆盖已入金未交易、活跃交易、开户审核、账户维护四种模拟状态。风险等级与有效期独立展示，不用财富高低推断风险偏好或触发营销。

## 一期功能与验收

| 功能 | 已交付行为 | 验收入口 |
|---|---|---|
| 公开规则 | 固定 FAQ 或检索完整依据句 | 开户材料、可用与可取区别 |
| 语义路由 | DeepSeek Schema 分类后执行对应流程 | 口语开户进度查询 |
| 个人资格 | 鉴权→画像和测试规则→逐项校验 | 我能不能开创业板 |
| 订单诊断 | 订单号澄清、归属验证、状态与原因码 | 我的委托为什么没成→ORD1002 |
| 账户/资金/测评/持仓 | 读取当前模拟账户工具 | U1003 开户、U1004 测评、U1002 持仓 |
| 合规处理 | 输入风险拦截、输出依据约束与审计 | 投资建议、代客操作、越权、注入 |
| 失败处理 | 低置信澄清、模型或工具失败转本地工单 | 未知问题、错误订单号 |
| 会话 | SQLite 保存、刷新恢复、切换身份清除私有上下文 | 刷新/退出/切换账户 |
| 人工协同 | 保存摘要、身份状态、本地工单号 | 服务工单页；无真实坐席 |
| 评测 | 主/留出数据、逐条断言、风险与检索指标 | 评测页及 eval/report.json |
| 可观测性 | 每条回答引用与处理记录、实际用量、导出 | 处理记录面板 |

## 架构与实现要求

采用 Router + 确定性 Workflow + 局部受控 Agent Loop。复杂私有查询由模型选择白名单只读工具，模型不能直接改变身份、订单资源、业务数据或执行交易。单轮最多 6 个动作，重复动作、未知工具、非法参数、证据不足或预算超限停止处理。

没有密钥时采用固定工具流程。两种模式在审计中区分，不能将纯规则执行包装成模型推理。

## 知识与事实治理

当前 14 条知识均为本项目演示说明，含来源、版本、受众、有效期、审核状态和直接回答权限。检索为显式同义改写、业务域选择、关键词及中文双字词项排序；未引入外部 embedding 或神经重排。

模型仅选择原文完整句子；程序检查引用 ID、数字和整句匹配。未通过时回退引用原文，避免自由生成带来无依据建议。账户事实从工具返回生成。无官方原文支撑的监管数字不进入确定性知识答案。资格演示规则始终标记为测试数据。

## 安全与数据

只绑定本机地址，密钥放进程环境或 macOS 钥匙串，前端不可读取。用户输入中的密钥、长号码和显式密码/验证码会脱敏。公共写请求限制跨站来源。模拟账户选择不是生产身份认证；不存在真实二次鉴权、机构 SSO、监管审计留存和多租户隔离能力。

仅保存本地演示会话、工单与反馈。会话读取 24 小时后过期，尚未做自动物理清除；不接受真实客户数据。

## 评测与指标

目标北极星为合规前提下一次解决率。该阶段仅交付离线契约评测与真实模型烟测，分别报告分母。风险误杀/漏拦截、意图、依据命中、状态和关键事实检查可复现；事实全面性与自然度的专业人工评测、Judge 校准和真实客户指标尚未执行。

## 非目标与上线差距

没有真实券商、行情、银行或坐席接入；没有交易执行、投顾建议或个性化推荐。当前项目不是可以直接给真实客户使用的生产系统。

生产化需要：正式业务需求和真实样本、专业审核知识与规则、真实身份与权限体系、券商接口及幂等容错、坐席接入、隐私与保留策略、并发负载评测、模型版本治理和合规验收。相关能力不能因个人项目验收完成而被宣称已经落地。
